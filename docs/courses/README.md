2026-11-05 so they survive without the Claude project. They are **history and
templates**, not current rules: where they differ from `CLAUDE.md`,
`AGENTS.md` or `docs/HANDOFF.md`, those win. Known differences:

  "≤ 25 words" lines below are out of date. See HANDOFF § Content rules.

  `/mnt/project-files/medstudy/...` point at the source folder that lives
  outside git (HANDOFF § Sources outside git).

  exist; any agent can do that work now.
